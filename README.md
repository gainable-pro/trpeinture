# TR Peinture (Deployment Retrigger)

Site vitrine haute performance pour une entreprise de peinture en bâtiment et rénovation.
Développé avec Next.js 14, Tailwind CSS et optimisé pour le SEO Local.


[![Vercel](https://therealsujitk-vercel-badge.vercel.app/?app=trpeinture)](https://vercel.com/gainable-pro/trpeinture)

## 🚀 Fonctionnalités

*   **Design Premium** : Charte graphique soignée (Bleu Nuit / Doré).
*   **Performance** : Score Lighthouse élevé, chargement rapide.
*   **SEO Local** : 30 pages villes générées automatiquement pour le référencement.
*   **Pages Services** : Peinture, Placo, Sols, Rénovation.
*   **Capture de Leads** : Formulaires de contact et devis.

## 🛠️ Stack Technique

*   **Framework** : [Next.js](https://nextjs.org/) (App Router)
*   **Styling** : [Tailwind CSS](https://tailwindcss.com/)
*   **Icônes** : [Lucide React](https://lucide.dev/)
*   **Déploiement** : Vercel

## 📦 Installation Locale

```bash
npm install
npm run dev
```

## 🌍 Déploiement

Le site est connecté à Vercel. Chaque push sur la branche `main` déclenche un déploiement automatique.
